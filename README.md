🖥️ Velora

Velora is a browser-based desktop environment. It combines a clean interface with interactive apps, making it feel like a real desktop while still being simple and easy to use.



💻 Features

Velora currently includes:

🕒 Live clock with 12/24-hour format

🌤️ Real-time weather widget

📝 Notes app

🧮 Calculator

⚙️ Settings panel

🎨 Theme customization

🔍 Desktop search with Google integration

🖱️ Draggable app windows


💬 How to Use Velora

You can interact with Velora by:

● Opening apps from the desktop

● Searching for apps or the web using the search bar

● Writing notes

● Performing calculations

● Changing themes in Settings

● Moving windows around your desktop

🛠️ Built With

● HTML5 — Structure of the application

● CSS — Styling and desktop interface

● JavaScript — Functionality and interactivity

● Open-Meteo API — Live weather information

● Google Fonts — Typography

● GitHub — Version control and source code hosting
